# Shared device tree for the Redmi K50 (rubens) and Redmi K60E (rembrandt)

Redmi K50 (codenamed "rubens") and Redmi K60E (codenamed "rembrandt") are mid-to-high-end smartphones from Xiaomi. Released in March 2022 (K50) and December 2022 (K60E) respectively.

## Device Specifications

|Models|Redmi K50 (rubens)|Redmi K60E (rembrandt)|
|---|---|---|
|CPU|Octa-core (4x Arm Cortex-A78 up to 2.85GHz)|Octa-core (4x Arm Cortex-A78 up to 3.10GHz)|
|Chipset|Mediatek Dimensity 8100|Mediatek Dimensity 8200|
|GPU|Mali-G610 MC6|Mali-G610 MC6|
|Memory|8/12 GB RAM (LPDDR5 6400Mbps)|8/12 GB RAM (LPDDR5 6400Mbps)|
|Shipped Android Version|12 with MIUI 13|12 with MIUI 13|
|Storage|128/256/512 GB (UFS 3.1)|128/256/512 GB (UFS 3.1)|
|Battery|Non-removable Li-Po 5500 mAh|Non-removable Li-Po 5500 mAh|
|Display|1440 x 3200 pixels, 6.67 inches, 120 Hz, AMOLED, HDR10+|1440 x 3200 pixels, 6.67 inches, 120 Hz, AMOLED, HDR10+|
|Camera|48MP (Primary) 8MP (Ultra-wide) 2MP (Telephoto-macro)|48MP (Primary) 8MP (Ultra-wide) 2MP (Telephoto-macro)|
